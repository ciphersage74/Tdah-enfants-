# Assets requis

Place ici les images suivantes avant le build Play Store :

| Fichier | Taille | Usage |
|---------|--------|-------|
| `icon.png` | 1024×1024 | Icône principale de l'app |
| `splash.png` | 1242×2436 | Écran de chargement |
| `adaptive-icon.png` | 1024×1024 | Icône adaptive Android |
| `notification-icon.png` | 96×96 (blanc sur transparent) | Icône notification Android |

## Couleur de fond splash : `#6C3AE8` (violet FocusHéros)

Tu peux créer ces images gratuitement sur https://www.canva.com
ou avec DALL-E / Midjourney pour l'icône.
